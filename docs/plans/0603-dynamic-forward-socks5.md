# Plan 0603: 动态转发 `-D`（SOCKS5）

- **关联**：ROADMAP 阶段 6 ·「动态转发 `-D`（本地 SOCKS5 服务端）」
- **前置**：plan 0601（隧道实体与状态机）· plan 0503（原语）
- **状态**：未规划（骨架）
- **展开时机**：本地转发跑通之后（`-L` 是单目标，`-D` 是它的多目标版本）

## 目标

在本机起一个 **SOCKS5 服务端**，把每个目标经 `direct-tcpip` 送出去。

⚠️ 这个 SOCKS5 服务端**要自己实现**（依赖系统组件不可接受，P1）——
工作量与"顺手就能有"有区别，展开时要如实估计。

## 非目标

- SOCKS5 的扩展特性（UDP associate、认证协商）：v1 只做无认证的 CONNECT
- HTTP 代理 / 其他代理形态

## 判据（来自 ROADMAP，展开时必须变成可粘贴的验收命令）

配置 SOCKS5 代理后**能访问远端网络**。

## 展开时要补

- [ ] 「## 步骤」：SOCKS5 的握手与 CONNECT 报文处理；绑定地址与端口从转发规则池取
- [ ] 「## 验收命令」：用现成客户端（如 `curl --socks5`）访问一个只有远端可达的地址
- [ ] 安全项：默认**只绑定回环** —— 绑到 `0.0.0.0` 等于把内网代理开放给同网段，必须显式选择
