# Plan 0701: SFTP 双栏界面骨架 + 两侧独立选主机

- **关联**：ROADMAP 阶段 7 ·「双栏界面骨架 + 两侧独立选主机（**不需要先开终端 Session**）」
- **前置**：阶段 5（能建立 SSH 连接）· 阶段 4（主机从池中选择）
- **状态**：未规划（骨架）
- **展开时机**：阶段 7 开工时

## 目标

双栏 SFTP 界面：左右两侧各自从池中选择主机（类似 Termius 的 sftp 页，`scope.md` §4）。
**两侧独立**，且**不依赖终端 Session** —— 后端不得假设"先有终端才有连接"（`scope.md` §5.1）。

## 非目标

- 传输本身（plan 0702 / 0703 / 0704）—— 本 plan 只做骨架与两侧连接建立
- 拖拽 / 快捷键 / 多选等交互打磨（UI 阶段）
- 断点续传（`later`，`scope.md` §10）

## 判据（来自 ROADMAP，展开时必须变成可粘贴的验收命令）

**直接打开 SFTP 即可用，无终端依赖**。

## 展开时要补

- [ ] 「## 步骤」：SFTP 作为一个独立 `Session` 类型落在 `SessionRegistry` 里（`SessionKind::Sftp`）
- [ ] 「## 验收命令」：不打开任何终端的前提下，两侧各自列目录成功
- [ ] 呈现形式仍属前端（`scope.md` §1.2）：后端只提供按 `SessionId` 路由的数据
