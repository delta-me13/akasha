# Plan 0503: `direct-tcpip` 原语

- **关联**：ROADMAP 阶段 5 ·「`direct-tcpip` 原语（本阶段先用于跳板）」
- **前置**：plan 0502（能连上、能认证）
- **状态**：未规划（骨架）
- **展开时机**：`akasha-ssh` 能稳定连接之后

## 目标

实现一次 `direct-tcpip` channel 链式串接，落在 `src-tauri/crates/akasha-ssh`，**供三处复用**：

1. **跳板 / ProxyJump**（本阶段）
2. SFTP host↔host 的 **B 档**（阶段 7）
3. **SSH 本地转发**（阶段 6）

先做跳板 = 顺手拿到另外两处的地基（`scope.md` §2.2）。

## 非目标

- **远程转发（`-R`）不在本原语范围内**：那是另一套机制（服务端发起 `forwarded-tcpip`），
  别把它和本地转发混为一谈
- 隧道实体的状态机（plan 0601）：本 plan 只做原语，不做生命周期

## 判据（来自 ROADMAP，展开时必须变成可粘贴的验收命令）

ProxyJump 可连通**只对跳板机可见**的目标。
