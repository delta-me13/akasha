# Plan 0702: local ↔ host 传输（临时名 + 原子重命名）

- **关联**：ROADMAP 阶段 7 ·「local ↔ host 双向；**临时名 + 原子重命名**落盘」
- **前置**：plan 0701（双栏与两侧连接）
- **状态**：未规划（骨架）
- **展开时机**：双栏骨架可用之后

## 目标

双向传输，落盘一律**先写临时名，完成后原子重命名**（`scope.md` §4.2）：

| 时机 | 行为 |
|---|---|
| 传输中 | 写到目标目录下的临时名（如 `.name.part`） |
| 成功 | 原子 `rename` 成最终名 |
| 失败 / 取消 / **关闭 Session** | **删除临时文件** |

关键不变量：**用户看到最终名就等于成功** —— 半截文件绝不能伪装成完整文件。

## 非目标

- 断点续传（`later`）：需要记录偏移量与远端校验，不是"顺手就能有"
- host ↔ host（plan 0703）与并发 in-flight（plan 0704）

## 判据（来自 ROADMAP，展开时必须变成可粘贴的验收命令）

中断传输后目标目录里**没有**冒充完整的文件。
