# Plan 0404: dump 与导出

- **关联**：ROADMAP 阶段 4 ·「dump 与导出（可选加密；明文导出必须二次确认）」
- **前置**：plan 0403（四套池的 CRUD 已完成）
- **状态**：未规划（骨架）
- **展开时机**：CRUD 稳定之后

## 目标

- **dump**：可见性工具（库里到底有什么，可诊断）
- **导出**：可选是否加密；**加密导出用独立口令**（不复用库口令），自包含、可直接给另一台机器用
- **明文导出**：**必须显式二次确认 + 明示内容含私钥**，不许作为默认选项（`scope.md` §6）

导出是**最高危的操作**，因为库里含私钥 —— 门槛要写进实现，不能只写在文档里。

## 非目标

- Bitwarden 的写回（`later`，`scope.md` §10）
- 跨版本迁移工具（有数据文件格式变更时再单独立项；格式版本字段属于 plan 0400 的决策）

## 判据（来自 ROADMAP，展开时必须变成可粘贴的验收命令）

- **加密导出可在另一目录导入还原**
- 明文导出路径有**显式确认门槛**（不是一条默认勾选的选项）

## 展开时要补

- [ ] 「## 步骤」：导出格式（由 plan 0400 定）→ 加密导出 → 导入还原 → 明文导出的确认门槛
- [ ] 「## 验收命令」：导出 → 换目录导入 → 断言池内容一致；明文路径的门槛如何被测到
- [ ] 安全项：导出文件的默认落点与权限（含私钥，别写进世界可读的目录）
