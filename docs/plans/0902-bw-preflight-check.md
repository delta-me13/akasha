# Plan 0902: 前置检查 —— 探测 `bw` 及其变体

- **关联**：ROADMAP 阶段 9 ·「前置检查：探测 `bw` **及其变体**」
- **前置**：plan 0901（需要知道如何分辨变体，才能正确探测）
- **状态**：未规划（骨架）
- **展开时机**：plan 0901 有结论之后

## 目标

启动时 / 使用前探测 `bw` CLI 及其变体，缺失时给出**可读报错并指明应安装哪个变体**。

⚠️ 这是**显式前置依赖**，不是静默降级：未安装的机器上该功能整体不可用，这是取舍，
但用户须能从报错中确定处理方式（`scope.md` §7）。

## 非目标

- **不打包 `bw`**（专有变体禁分发：法律要求，`scope.md` §10）
- 不自动安装、不下载二进制

## 判据（来自 ROADMAP，展开时必须变成可粘贴的验收命令）

未安装 → 明确报出需安装 Bitwarden CLI，并**指明应安装的变体**；专有变体 → 给出提示。

## 展开时要补

- [ ] 「## 步骤」：探测顺序与路径来源（`PATH` / 用户配置）、版本与变体判定
- [ ] 「## 验收命令」：在**没有 `bw`** 的环境里执行一次，将实际报错粘贴进「实施记录」
- [ ] 检查时机：启动即检查（并缓存结论）还是首次使用时检查 —— 决定启动耗时，须先确定再实现
