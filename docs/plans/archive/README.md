# 已归档的 plan

**这里只放已完成的 plan，整份移动，永不拼接。**

规则（完整版见 [`../README.md`](../README.md)）：

1. plan 完成后：状态改「已完成」→ `git mv` 进本目录 → [`../README.md`](../README.md) 的索引**保留一行**，
   文件链接改指本目录路径。索引因此始终是全部 plan 的单一入口。
2. **不许**把多份 plan 合并成一份「阶段汇总」，也**不许**往已完成的 plan 里追加后续工作。
   需要新工作就开新编号 —— 「一个文件越滚越大」正是要靠这条规则防住的事。
3. 每份 plan 同样受 **≤ 200 行**预算约束（由 `just docs-check` 检查）。

每个已归档的 plan 在 [`../README.md`](../README.md) 的索引里**各留一行** —— 那里才是
全部 plan（含在做的）的单一入口；本目录只有「已完成」这一种状态。
