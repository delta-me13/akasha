# Plan 0802: 端口枚举与连接参数

- **关联**：ROADMAP 阶段 8 ·「端口枚举与连接参数（波特率/数据位/停止位/校验/流控）」
- **前置**：plan 0801（serial crate 与 feature 结构）
- **状态**：未规划（骨架）
- **展开时机**：serial crate 可用之后

## 目标

枚举本机串口，并用完整参数打开：**波特率 / 数据位 / 停止位 / 校验 / 流控**。
参数集与 serial 配置池（阶段 4 的池，plan 0403）对齐。

## 非目标

- 串口协议的解析（仅转发字节，不实现协议栈）
- 热插拔事件驱动的自动重连（先手动；libudev 缺失时的降级见 plan 0801）

## 判据（来自 ROADMAP，展开时必须变成可粘贴的验收命令）

枚举在**本机列出真实端口**；**参数错误时给出可读报错**。

## 展开时要补

- [ ] 「## 步骤」：枚举的返回结构（路径 + 描述）、打开失败的分类报错
- [ ] 「## 验收命令」：本机没有串口设备时的行为（不能硬失败）；用 `socat` 创建一对虚拟串口做自动验证
- [ ] 参数非法组合（例如停止位 1.5 与某些校验位）的处理：拒绝并说明，不得透传底层错误
