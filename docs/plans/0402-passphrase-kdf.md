# Plan 0402: 口令 → KDF → 库密钥

- **关联**：ROADMAP 阶段 4 ·「口令 → KDF → 库密钥（**不依赖 OS keychain**）」
- **前置**：plan 0400（ADR-0002 定案）· plan 0401（库能开）
- **状态**：未规划（骨架）
- **展开时机**：ADR-0002 定案后

## 目标

用户口令经 KDF 派生库密钥，**口令不落盘**，且**不依赖任何 OS 凭据库**（P1，`scope.md` §1）。

算法与参数（盐、成本、存放位置）由 ADR-0002 定，**本 plan 不自行决定**。

## 非目标

- 凭据池的内容管理（plan 0403）
- Bitwarden 的 `bw` 交互（阶段 9）：它只是机密的另一个来源
- 记忆口令 / 自动解锁 —— 与"不依赖 OS keychain"冲突，不在 v1

## 判据（来自 ROADMAP，展开时必须变成可粘贴的验收命令）

- **无任何 `keyring` 类依赖**（`cargo tree` 可证）
- 口令不以任何形式出现在磁盘上（配置文件、日志、临时文件都不行）

## 展开时要补

- [ ] 「## 步骤」：KDF 参数从 ADR-0002 抄过来，并写清盐 / nonce 存哪
- [ ] 「## 验收命令」：`cargo tree` 的断言 + 解锁失败路径的实际报错
- [ ] 与 plan 0401 的库打开路径合并后的**单测**形态（错误口令 / 正确口令）
