# Plan 0602: 本地转发 `-L`

- **关联**：ROADMAP 阶段 6 ·「本地转发 `-L`（复用阶段 5 的 `direct-tcpip`）」
- **前置**：plan 0601（隧道实体与状态机）· plan 0505（原语）
- **状态**：未规划（骨架）
- **展开时机**：隧道实体可用之后

## 目标

本地监听端口 → 经 SSH 连接上的 `direct-tcpip` channel → 远端目标。

这是三处复用**同一个原语**的第三处（前两处：跳板、SFTP B 档）——
本 plan **只做接线**，不重写原语。

## 非目标

- 动态转发（plan 0603）与远程转发（plan 0604）
- 重连（plan 0605）：本 plan 先做到"能转发 + 状态可见"，连接中断则进入"失败"态，交由 0605 处理

## 判据（来自 ROADMAP，展开时必须变成可粘贴的验收命令）

转发端口**可访问远端服务**。

## 展开时要补

- [ ] 「## 步骤」：本地监听的绑定地址与端口从转发规则池取（阶段 4 的池，plan 0403）
- [ ] 「## 验收命令」：可复现的目标（本地 sshd 容器 + 一个只有远端能访问的服务）
- [ ] 端口被占用的报错形态（这是用户最常遇到的一类失败，必须可读）
