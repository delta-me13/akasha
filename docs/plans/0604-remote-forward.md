# Plan 0604: 远程转发 `-R`

- **关联**：ROADMAP 阶段 6 ·「远程转发 `-R`（`tcpip-forward` + `forwarded-tcpip`，**另一套机制**）」
- **前置**：plan 0601（隧道实体与状态机）
- **状态**：未规划（骨架）
- **展开时机**：本地转发（plan 0602）运行通过之后

## 目标

向服务端发 `tcpip-forward` 全局请求，并处理服务端发起的 `forwarded-tcpip` channel，
把远端监听端口回连到本机服务。

## 非目标

- **不复用 `direct-tcpip` 原语**：方向相反（服务端发起连接），复用即为方向错误
  （`scope.md` §2.2 的例外说明）
- 本地转发 / 动态转发（plan 0602 / 0603）

## 判据（来自 ROADMAP，展开时必须变成可粘贴的验收命令）

远端监听端口**可回连到本机服务**。

## 展开时要补

- [ ] 「## 步骤」：服务端拒绝 `tcpip-forward`（端口被占 / 服务端禁止）时的处理 —— 这是常见失败态
- [ ] 「## 验收命令」：可复现的远端（sshd 容器）与一个**只在本机监听**的服务
- [ ] 与状态机的接线：远端请求失败应落到 `失败` 态并**在托盘可见**（`scope.md` §5.2）
