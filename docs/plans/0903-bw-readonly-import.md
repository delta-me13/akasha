# Plan 0903: 只读导入 SSH key 条目

- **关联**：ROADMAP 阶段 9 ·「只读导入 SSH key 条目（`sshKey.privateKey`）」
- **前置**：plan 0901（字段形状已实测）· plan 0902（前置检查）· 阶段 4（本地密钥池）
- **状态**：未规划（骨架）
- **展开时机**：plan 0901 / 0902 完成之后

## 目标

把 Bitwarden 的 SSH key 条目**只读导入**本地池：**不写回上游**（v1 只读，`scope.md` §7）。

导入池与本地密钥池之间**没有任何同步机制** —— 是"快照 + 显式导入"，不是 cache。

## 非目标

- 写回 Bitwarden（`later`，`scope.md` §10）
- 其他条目类型（登录 / 笔记等）—— 只做 SSH key
- 私钥落盘：导入后私钥存库（阶段 4），**不落临时文件**（`scope.md` §3）

## 判据（来自 ROADMAP，展开时必须变成可粘贴的验收命令）

导入后**可用该密钥建立 SSH 连接**。
