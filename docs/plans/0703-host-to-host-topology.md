# Plan 0703: host ↔ host（B 档优先，回退 A 档）

- **关联**：ROADMAP 阶段 7 ·「host ↔ host：**优先 B 档（`direct-tcpip`），失败回退 A 档（内存 relay）**」
- **前置**：plan 0702（传输引擎）· plan 0505（`direct-tcpip` 原语）
- **状态**：未规划（骨架）
- **展开时机**：local ↔ host 传输稳定之后

## 目标

两档都实现，运行时**优先 B**：

| 档 | 机制 | 前置条件 |
|---|---|---|
| **B（优先）** | 在到 A 的 SSH 连接上开 `direct-tcpip` 直通 B，SFTP 跑在隧道里 | A 必须能连到 B |
| **A（回退）** | 内存 relay：读 A → 写 B | 无，**永远可用** |

**两档都不落盘**（全程流式）。B 并不绕开本机 —— 它只是把本机带宽砍半，
并解除"本机必须能直达 B"的限制（`scope.md` §4.1）。

## 非目标

- **"真不中转"**（在 A 上跑 `rsync`）：已在 `scope.md` §10 列为 `no`
- 断点续传（`later`）

## 判据（来自 ROADMAP，展开时必须变成可粘贴的验收命令）

A 无法直连 B 时**自动走 A 档**；两档**均不落盘**。

- [ ] 「## 验收命令」：需要一个 A 能连 B、而本机不能连 B 的拓扑（容器网络是常见做法）
