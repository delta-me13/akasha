# Plan 0606: 关闭 Session 断连 + 中止重连

- **关联**：ROADMAP 阶段 6 ·「关闭 `Session` 立刻断连，并中止该 `Session` 的重连循环」
- **前置**：plan 0605（重连循环存在，才有"中止"可言）
- **状态**：未规划（骨架）
- **展开时机**：重连与转发都运行通过之后

## 目标

关闭一个 Session 时：

1. 它的连接**立刻关闭** —— 无宽限期、无延迟回收（`scope.md` §2.2）
2. 它正在进行的**重连循环被中止** —— 否则会留下"没有 Session 的重连任务"：
   对一个已不存在的对象反复重试，持续扰动网络，而且**没有任何地方能显示它的状态**
3. 它之上正在进行的一切（例如未完成的 SFTP 传输）被中止，临时文件按 `scope.md` §4.2 删除

**这是"连接 = Session 生命周期"这条定案的执行点**，也是唯一能保证零残留的地方。

## 非目标

- 窗口关闭的语义：**窗口关闭（默认收托盘）不影响任何连接**（plan 0302 已定，方向相反，不得反置）
- 应用退出的全量回收（plan 0204 的入口，本 plan 只补上隧道类资源）

## 判据（来自 ROADMAP，展开时必须变成可粘贴的验收命令）

关闭转发 Session 后**连接数与重连任务数都归零**。
