# Plan 0502: `src-tauri/crates/akasha-ssh` —— 连接 + 认证

- **关联**：ROADMAP 阶段 5 ·「`src-tauri/crates/akasha-ssh`：连接 + 认证（密钥池 / agent / 内存凭据缓存）」
- **前置**：plan 0501（ADR-0003 定案）· 阶段 4（密钥池可取用）
- **状态**：未规划（骨架）
- **展开时机**：ADR-0003 定案后

## 目标

纯 Rust SSH（**不调系统 `ssh`**）：连接 + 认证，认证来源按优先级取用 ——
SSH agent 优先、密钥池次之、**内存凭据缓存**兜住"同一主机多次连接不重复问"。

不复用连接（一实体一连接）带来的副作用必须由本 plan 处理：到同一主机开三个 Session
会握手三次，若用密码 / 2FA 就会被问三次 —— **不可接受**（`scope.md` §2.2）。

## 非目标

- 端口转发（阶段 6）与 `direct-tcpip` 原语（plan 0503）
- `~/.ssh/config` 导入（plan 0504）与 known_hosts（plan 0505）—— 但它们会**改本 plan 的接口**，
  展开时先回看那两份骨架
- SFTP（阶段 7）

## 判据（来自 ROADMAP，展开时必须变成可粘贴的验收命令）

同主机开三个 Session **只问一次凭据**。
