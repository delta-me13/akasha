# 归档

> 这里放**只移动、不改写**的历史：`ROADMAP.md` 里已完成的条目，`docs/STATUS.md` 里历史会话段、
> 被取代的读数与已处置的问题条目。规则与执行方式见 [`AGENTS.md`](../../AGENTS.md) §8.3，
> 入口是配方 `just docs-archive`（幂等）。

| 文件 | 装什么 | 为什么在这里 |
|---|---|---|
| [`roadmap-completed.md`](./roadmap-completed.md) | `- [x]` 的 ROADMAP 条目，按阶段分节（含验收行与 plan 指针） | 「下一步做什么」不需要已完成的东西，但"这个阶段做过哪些事"仍有据可查 |
| [`status-history.md`](./status-history.md) | 历史摘要、被取代的读数（`↑` 行）、已处置的问题条目 | STATUS 只回答"现在在哪"；当时的判据与教训留在归档里 |

两条不许违反的口径：

- **编号永不复用**：`问题 #N` 与 plan 编号在条目移走之后仍然有效，原文就在这里 ——
  它同时是"这条结论当时是怎么得出的"的唯一去处，改写等于毁掉证据（`AGENTS.md` §8.3）。
- **plan 不在这里**：已完成的 plan 走 [`../plans/archive/`](../plans/archive/)，两者的归档对象不同
  （一个是"去哪"的条目，一个是"怎么做"的工作项）。
